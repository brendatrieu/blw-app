---

Can't find a food? Add it yourself. A custom food is one ingredient, like papaya or cottage cheese. For something cooked from several ingredients, add a recipe instead.

## 1. Name it

Type the food's name. If you searched for it first, it's already filled in.

![The Name field reads Papaya, with the Add it as a recipe instead link below.](/guides/food-1-name.webp)

## 2. Pick a category

Choose a **Category**. Under **Emoji (optional)**, type an emoji or use the emoji button to pick one; leave it empty for 🍽️.

![Category is set to Fruit, and the Emoji (optional) box is empty, showing 🍽️, with the 😀 emoji button beside it.](/guides/food-2-category.webp)

## 3. Tap its allergens

Tap any of the top 9 allergens the food contains. They count toward allergen tracking.

![Allergens lists the top 9 as chips, from Milk to Sesame, with none tapped for papaya.](/guides/food-3-allergens.webp)

## 4. Add a note and save

Add anything worth remembering in **Notes (optional)**, like how you cut it, then tap **Save**. Custom foods don't come with our prep, nutrition, or choking guidance, so check those yourself.

![Notes (optional) reads "Peeled, seeded, and cut into finger-length strips," with the Save button below.](/guides/food-4-save.webp)
